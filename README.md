# CSC1025 Django Project

## Fan or Fraud?
A user friendly quiz website on TV Programmes.

### Purpose
Test users' knowledge on their favourite TV shows and programmes created by other users.

### Distinct Functionalities

#### - User profiles
- Register and login and have their own profile. Users can set their own customized bio and profile picture via an image upload. 
- Users can generate their own quizzes on chosen TV Programme by adding a multiple based question.
- Users can see their previous quiz attempts and history and compare with others.
	
#### - Quiz application
- Users can take other available quizzes, and their own quiz.
- Users created quizzes are saved and can be updated/ deleted on demand.

#### - Boundless TV Programmes to choose from
- All series are pulled from OMDb's movie database via it's RESTful web service, meaning any show that exists, can have it's own quiz.
